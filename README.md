🧠 AI-Powered Finance Management System

This project is an intelligent, full-featured personal finance management system designed to help users take control of their budgets, track transactions, and gain insights into their spending habits using artificial intelligence. It offers secure authentication, automated receipt scanning, budgeting tools, visual analytics, and smart financial suggestions — all in one platform.

✨ Key Features
🔐 User Authentication & Profile Management (Email/Password + OAuth)
💰 Budget Planning & Monitoring (Monthly categories, live updates)
💳 Transaction Management (Add, edit, categorize, and filter)
🧾 AI Receipt Scanner (OCR-powered image scanning with auto-categorization)
📊 Visual Reports (Pie charts, bar graphs, spending summaries)
🧠 AI Insights (Spending analysis, smart budgeting, fraud detection)
🌙 Dark Mode and responsive UI using Tailwind CSS
☁️ Cloud-Hosted with MongoDB, Express.js, React, and Node.js (MERN Stack)

🏗️ Tech Stack
Frontend: React.js, Tailwind CSS
Backend: Node.js, Express.js
Database: MongoDB (with Mongoose)
AI/OCR: Tesseract.js (or equivalent OCR engine)
Authentication: JWT, Google OAuth
Deployment: Vercel / Netlify (Frontend), Render / Railway / Heroku (Backend)

📌 Project Goals
Empower users to manage finances with minimal manual effort
Use AI to simplify receipt processing and financial decision-making
Deliver a seamless, modern user experience with visual and data-driven tools
Maintain high standards of security and data privacy

🚀 Getting Started
To run the project locally:
# Clone the repo
git clone https://github.com/your-username/ai-finance-system.git

# Install backend dependencies
cd backend
npm install

# Install frontend dependencies
cd ../frontend
npm install

# Start both servers
npm run dev

Make sure to configure your .env file with the appropriate environment variables (MongoDB URI, JWT secret, etc.).
